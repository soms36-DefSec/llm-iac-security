# CIS AWS Foundations Benchmark

## 2.1.1 — S3 Encryption at Rest
Ensure all S3 buckets employ encryption-at-rest using AES-256 or AWS-KMS.

## 2.1.2 — S3 Versioning
Enable versioning on all S3 buckets to prevent data loss.

## 3.1 — Security Groups
Ensure no security groups allow unrestricted inbound access on port 22 (SSH).

## 1.16 — IAM Policies
Ensure IAM policies are attached only to groups or roles, never directly to users.
